1. Introduction                               *albus-conflictius-introduction*

albus-conflictius.nvim watches your repo for git merge/rebase/cherry-pick
conflicts from any tool, pops up a dashboard of conflicted files, and offers
a magic wand that auto-resolves hunks where only one side actually changed —
the Neovim equivalent of WebStorm's conflict resolution wand.

==============================================================================

3. Commands                                       *albus-conflictius-commands*

:AlbusConflictius                                       *:AlbusConflictius*
    Open the conflict dashboard for the current repo now.

    Show the wizard art and a command/keymap reference.

4. Resolve view keymaps                        *albus-conflictius-resolve-view*

Opening a file with remaining conflicts (`<CR>` in the dashboard) drops the
cursor on the first conflict and enables these buffer-local keymaps:

    <CR>          accept whichever side (ours/theirs) the cursor is on
    <leader>co    accept ours for the hunk under the cursor
    <leader>ct    accept theirs for the hunk under the cursor
    <leader>cb    accept both (ours then theirs)
    <leader>cn    jump to the next conflict
    <leader>cp    jump to the previous conflict
    <leader>cw    run the wand on this file (acts on the buffer, not disk)
    <leader>cd    toggle an ours | result | theirs 3-pane diff view
    q             close the diff panes if open, else close the whole view
    :w            save -- auto-stages and closes the tab once no markers remain

<CR> works the same way everywhere: in the single-pane view it looks at
which side of the hunk (ours or theirs text) the cursor's line falls in and
accepts that side; in the 3-pane view it's simply whichever pane you're in.
On a marker line itself, it warns instead of guessing.

`<leader>cd` opens two extra read-only panes around the real file: "ours" on
the left, "theirs" on the right, each showing what the file would look like
if every remaining hunk were resolved to that side.
`q` closes the diff panes first (non-destructive, <leader>cd reopens them);
pressed again it closes the whole view, prompting for confirmation only if
conflicts still remain.

The "ours" and "theirs" side of each remaining hunk are background
highlighted (|hl-DiffDelete| and |hl-DiffAdd| by default) so they're
visually distinct without reading the marker text. Override
`AlbusConflictiusOurs`/`AlbusConflictiusTheirs` to customize.

==============================================================================
5. Celebration                                 *albus-conflictius-celebration*

When the last conflicted file in the repo is resolved, the dashboard plays a
short animation before closing: colorful fireworks, a sweeping laser beam,
the wizard mirror-flipping in place, and a whimsical banner message picked
once at random (e.g. "ALAKAZAM! ALL CONFLICTS VANISHED!"). Press <CR>, q, or
<Esc> to skip it. Disable it entirely with `celebrate = false` (see
|albus-conflictius-configuration|).
