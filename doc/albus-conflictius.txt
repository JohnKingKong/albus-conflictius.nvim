1. Introduction                               *albus-conflictius-introduction*

albus-conflictius.nvim watches your repo for git merge/rebase/cherry-pick
conflicts from any tool, pops up a dashboard of conflicted files, and offers
a magic wand that auto-resolves hunks where only one side actually changed —
the Neovim equivalent of WebStorm's conflict resolution wand.

==============================================================================
2. Setup                                             *albus-conflictius-setup*

>lua
    require("albus-conflictius").setup({})
<

==============================================================================
3. Commands                                       *albus-conflictius-commands*

:AlbusConflictius                                       *:AlbusConflictius*
    Open the conflict dashboard for the current repo now.

:AlbusConflictiusHelp                               *:AlbusConflictiusHelp*
    Show the wizard art and a command/keymap reference.

==============================================================================
4. Resolve view keymaps                        *albus-conflictius-resolve-view*

Opening a file with remaining conflicts (`<CR>` in the dashboard) drops the
cursor on the first conflict and enables these buffer-local keymaps:

    <leader>co    accept ours for the hunk under the cursor
    <leader>ct    accept theirs for the hunk under the cursor
    <leader>cb    accept both (ours then theirs)
    <leader>cn    jump to the next conflict
    <leader>cp    jump to the previous conflict
    <leader>cd    toggle a full base/ours/theirs diff view alongside it
    :w            save -- auto-stages once no markers remain

==============================================================================
5. Configuration                             *albus-conflictius-configuration*

>lua
    require("albus-conflictius").setup({
      banner = true,
      auto_stage = true,
    })
<
